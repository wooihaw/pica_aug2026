Python for Instrument Control and Automation

Use Python to compute, visualise and analyse measurement data, build simple instrument front panels, and drive bench instruments over serial and VISA.

00 No instrument required

The repository ships with two virtual instruments — a bench digital multimeter and a digital storage oscilloscope — that speak real SCPI over a real TCP socket. Each has a front panel with a live traffic log, so you can watch every byte your code sends and receives. The code you write against them is the code you would run against hardware; only the resource string changes.

01 Learning outcomes

By the end of the training, participants will be able to:

  1. Demonstrate an understanding of basic Python programming.
  2. Use key Python libraries for numerical computation, data visualisation and data analysis.
  3. Create basic graphical user interfaces with PySimpleGUI.
  4. Connect to and control instruments using PySerial and PyVISA.

03 Before you arrive

Please set up your laptop before Day 1. It takes about 10 minutes, most of it downloading. Every step in the guide ends with a Check — run it and confirm the result before moving on.

  1. Read the setup guide. Follow PYTHON_SETUP.md — a step-by-step Windows walkthrough that installs uv, creates the project environment and verifies Jupyter Lab. No prior Python installation is needed.
  2. Get the files. Clone the repository or download the ZIP. 
    git clone https://github.com/wooihaw/pica_aug2026.git
  3. Install the dependencies. The guide walks through this with uv add, then verifies everything at once: 
    uv run python -c "import pyvisa, numpy, pandas, matplotlib, serial, PySimpleGUI; print('all imports OK')"
  4. Start Jupyter Lab and confirm the notebooks open. 
    uv run jupyter lab
Work outside OneDrive. On most university and company laptops, Documents and Desktop are redirected into OneDrive, which tries to sync the thousands of small files in a virtual environment. Keep the project under C:\Users\<you>\python_venv\.

04 Virtual instruments

Run these from a terminal — not from inside a notebook — and leave them running while you work through the matching notebook. Put the front panel beside Jupyter so you can watch the traffic log as your commands go out. 

# Day 2, PySerial session
uv run python virtual_dmm.py

# Day 2, PyVISA session
uv run python virtual_scope.py
virtual_dmm.py A virtual bench multimeter in one file: signal source, instrument model, SCPI parser, TCP server, and a front panel with a 7-segment display, function keys and a traffic log. PySerial reaches it through socket://127.0.0.1:5025, which behaves exactly like a real serial port. Options: --headless, --port, --host, -v, --strict.
virtual_scope.py A virtual 2-channel digital storage oscilloscope speaking SCPI over TCP, with a PyVISA driver and a PySimpleGUI display layered on top — the layers talk over a real socket, not by calling each other's functions. Address it as TCPIP0::127.0.0.1::5025::SOCKET. Options: --sim-only, --no-sim, --resource, -v.
One at a time. Both simulators listen on port 5025. Run only one, or start the second with --port 5030 and update the address in your notebook.

05 Materials

Every notebook is meant to be edited, not read. Change a value, re-run the cell, see what breaks.

Notebooks

FileWhat it covers
Python Primer Variables, conditionals, loops, strings, lists, slicing, list comprehensions, tuples, dictionaries, file I/O, exception handling and functions.
NumPy Array creation, indexing and slicing, multi-dimensional arrays, random numbers, element-wise operations, aggregation, sorting and linear algebra.
Matplotlib Line plots, styling and annotation, scatter and bubble charts, histograms, bar and pie charts, subplots, 3D surfaces and displaying images.
Pandas Series and DataFrames, time-based indexing, resampling, missing data, reading CSV files, groupby, descriptive statistics, and plotting straight from a DataFrame.
Exercises Seven graded exercises: chickens and rabbits by brute force and again by linear algebra, temperature statistics with plain Python and with Pandas, average and RMS of a sinusoidal waveform, current and power from logged data, and plotting a downloaded waveform.
PySerial_DMM Opening a port, line termination and timeouts, commands versus queries, *IDN?, configuring a DC-volts measurement, logging 100 readings for mean and standard deviation, and draining the error queue.
PyVISA_Scope Resource manager and resource strings, checking the error queue, vertical and timebase settings (and why you always read a setting back), automatic measurements, downloading a waveform as an IEEE 488.2 block, and reading back what the front panel changed.

06 Working through the material

  • Run every cell yourself rather than reading the output.
  • On Day 2, keep the simulator's traffic log visible next to your code. Watching the bytes go out and come back is most of what makes instrument control click.
  • When something silently does nothing, check the error queue with SYST:ERR?. Instruments rarely complain out loud; they just drop the command.
